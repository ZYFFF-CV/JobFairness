# Stage1.1 M4 Outcome and Selection Screening Report

## Scope

This report evaluates the six no-user-id DeepFM/DCNv2 runs from CTR seeds
2019, 2020, and 2021. All prediction files contain the same 214,446 sequential
test rows. Diagnostics were generated by commit `f8a965f` and stored outside
the repository under the isolated Stage1.1 work directory.

The analysis is descriptive. Bootstrap repetition is limited to 20 for this
screen, and no result below is a formal confidence interval for publication.
The protected attribute remains a behavioral proxy and is not treated as
verified gender.

Symmetric proxy flips attenuate non-negligible DP by roughly 39% to 43% at a
20% rate. Random missingness preserves the original magnitude within about 5%.
The DCNv2 seed-2019 ratio is not meaningful because the denominator is near
zero. One-direction flips also attenuate magnitude in the non-negligible runs.
These perturbations change evaluator proxy labels only; they are not retraining
experiments and do not model verified demographic-label corruption.

## M4 decision

Available-data M4 screening supports the following:

1. all-logged and random-display scopes preserve DP direction but change its
   magnitude and predictive performance;
2. within-context disparity dominates the `displayrandom x rank` decomposition;
3. systematic proxy-label noise attenuates measured DP, while random missingness
   is comparatively stable;
4. interaction leakage must not be called harmful yet because no model-level
   selective intervention has linked leakage reduction to AUC, DP, calibration,
   U, or U_TILDE changes.

## External-data blocker and next boundary

`position_corrected` cannot be computed because `logging_propensity` is absent.
The protocol intentionally refuses to infer propensities from click outcomes or
current model predictions. Completing that scope requires one of:

- externally supplied logging propensities aligned by `row_id`; or
- a separately justified logging-policy model with a frozen train/validation
  protocol and no outcome leakage.

M5 introduces long fairness-method training. Before starting it, a decision is
required on whether position correction is deferred as unavailable or whether
external propensity data/modeling will be added. Any M5 matrix must compare
selective suppression, matched-random suppression, and global suppression with
identical seeds, training budgets, and validation-only Pareto selection.
